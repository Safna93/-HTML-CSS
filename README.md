# Reestar Food Website

Reestar is a simple food ordering website created using HTML and CSS.  
This project was developed to practice basic HTML structure and CSS styling.

## Features

- Navigation header
- Food recipe cards
- Food images and descriptions
- Order Now buttons
- Contact form
- Simple and clean layout

## Technologies Used

- HTML5
- CSS3

## What I Learned

Through this project, I practiced:

- Creating HTML elements and page structure
- Using div containers
- Working with images
- Styling elements using CSS
- Using `display: inline-block`
- Creating buttons and forms
- Connecting an external CSS file to HTML
